# Commit Guidelines

سننشئ commit لكل مرحلة رئيسية كما يلي (مثال للرسائل):

- feat: initial project structure
- feat(auth): implement JWT authentication
- feat(student): add student module CRUD
- feat(attendance): add attendance flow
- feat(reports): add exports and reports
- feat(whatsapp): integrate whatsapp-web.js
- feat(parent-portal): add parent portal
- chore: update dependencies / lint / prettier
